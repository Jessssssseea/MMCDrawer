# 抽签器应用说明

专为[揭阳第一中学数模队](jessssssseea.github.io/JYYZMMC)开发的抽签器。

## 简介
这是一个基于PySide2开发的抽签签应用程序，支持从Excel表格加载人员信息，按不同维度（组别、班级、性别、姓氏等）智能识别表头筛选抽签范围，并进行随机抽签操作。

## 功能特点
- 支持导入Excel表格数据
- 多维度筛选抽签范围（按组别、班级、性别、姓氏等）
- 动画式随机抽签效果
- 简单直观的用户界面

## 环境要求
- Python 3.8+
- 依赖库：
  - PySide2
  - pandas
  - openpyxl

## 安装步骤
1. 克隆或下载项目代码
2. 安装依赖包：
```bash
pip install pyside2 pandas openpyxl
```
或
```bash
pip install -r requirements.txt
```

## 使用方法
1. 运行主程序：
```bash
python main.py
```

2. 首次使用：
   - 点击"选定抽签范围"按钮
   - 选择包含人员信息的Excel文件
   - 在列识别向导中勾选可作为分类依据的列
   - 在编辑抽签范围窗口中选择参与抽签的人员

3. 抽签操作：
   - 点击"开始抽签"按钮启动随机滚动
   - 点击"停止抽签"按钮结束抽签并显示结果

## 文件结构说明
- `main.py`：主程序入口，实现主窗口逻辑
- `main_window.py`：主窗口UI定义
- `edit_range.py`：编辑抽签范围的窗口实现
- `roller.py`：实现抽签滚动动画效果
- `column_assistant.py`：Excel列识别辅助窗口

## 注意事项
- 确保Excel文件中包含"姓名"列
- 程序会记忆上次使用的Excel文件和列配置
- 支持多种分类方式，可在编辑窗口切换

## 界面预览
- 主界面：显示抽签区域和操作按钮
- 编辑范围窗口：可按不同维度筛选参与抽签的人员
